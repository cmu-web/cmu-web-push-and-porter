# Scotty

`avatar_default.png` is Scotty, Carnegie Mellon's mascot, from PlaceMellon's
default profile picture (https://placemellon.andrew.cmu.edu/200.png?profile),
drawn from University Communications and Marketing's Scotty artwork.

Scotty is a Carnegie Mellon University mark. The BSD license in `LICENSE`
doesn't cover it: use it only as CMU's brand guidelines allow
(https://brand.cmu.edu/).
