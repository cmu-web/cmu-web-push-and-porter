About Push & Porter

Push & Porter is a theme for Forgejo, the code hosting service. It brings Carnegie Mellon's web template and the Web Kilt to a Forgejo site, and leaves Forgejo itself as it is.

The Name

It's named for Porter Hall, on campus, and for the git push that sends your work to Forgejo.

Contributing to Push & Porter

Found a page that doesn't look right, or a Forgejo update that broke something? Open an issue in Push & Porter's GitHub repository.

More From CMU Web

Push & Porter is part of CMU Web, a collection of projects for Carnegie Mellon web development.
