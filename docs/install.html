Install Push & Porter

You need a Forgejo admin's access to its custom folder (CustomPath, often /var/lib/forgejo/custom or, in the container, /var/lib/gitea/custom).

Using an AI coding agent? Set Up With an AI Agent

  1. Download the latest release and copy its custom/public, custom/templates and custom/options into Forgejo's custom folder.
  2. In app.ini, keep your site's name, add the theme, make it the default and hide Forgejo's footer line: 
    APP_NAME = Your Site's Name

[ui]
THEMES = push-and-porter,forgejo-auto,forgejo-light,forgejo-dark
DEFAULT_THEME = push-and-porter

[other]
SHOW_FOOTER_POWERED_BY = false
SHOW_FOOTER_VERSION = false
SHOW_FOOTER_TEMPLATE_LOAD_TIME = false
  3. Restart Forgejo. Templates and labels load at startup; the CSS loads on each page.

People who already picked a theme keep it; they can switch under Settings › Appearance.

Your Site's Name and Address

  • The name is APP_NAME, in the header, the footer and every page title.
  • A line under the name (who runs the site, as a link or plain text, or a slogan) goes in custom/templates/custom/push-and-porter/site_line.tmpl as an <h2>. It's empty unless you add one.
  • The footer's address is custom/templates/custom/push-and-porter/address.tmpl. It starts with your site's name, then the university's address; replace it with yours.
  • Your own about page, with your site's licenses and credits, can go anywhere you like. Link it from the footer's address file or from Forgejo's custom/templates/custom/extra_links.tmpl.

What to Recheck on Forgejo Updates

The theme replaces no Forgejo pages. These are the files that follow Forgejo's version:

  • Forgejo's spots for additions, empty by default: custom/templates/custom/header.tmpl (the font and icons), body_inner_pre.tmpl (the CMU header and the menu strip) and footer.tmpl (the CMU footer). The menu strip repeats Forgejo's menu links and their conditions; check them against Forgejo's base/head_navbar.tmpl.
  • Forgejo's English labels, custom/options/locale/locale_en-US.ini and custom/options/locale_next/locale_en-US.json. A custom locale file replaces Forgejo's whole file, so they're built for one Forgejo version. Rebuild them for yours, or leave custom/options out and keep Forgejo's labels.
  • The default avatar, custom/public/assets/img/avatar_default.png.

Rebuild for Another Forgejo or Kilt

scripts/build.mjs builds custom/ from the repository's src/. Set FORGEJO or KILT in it, then: 

node scripts/build.mjs

It stops if one of the labels it changes is gone from that Forgejo version.
