About Hamerschlag

Hamerschlag is a theme for Forgejo, the code hosting service. It brings Carnegie Mellon's web template and the Web Kilt to a Forgejo site, and leaves Forgejo itself as it is.

The Name

Hamerschlag is named for Hamerschlag Hall, on campus. "Hammerschlag" is German for a hammer strike, which suits a theme for Forgejo: the name means "forge" in Esperanto.

Contributing to Hamerschlag

Found a page that doesn't look right, or a Forgejo update that broke something? Open an issue in Hamerschlag's GitHub repository.

More CMU Web Tools

Hamerschlag is part of CMU Web, a collection of projects for Carnegie Mellon web development. The collection also includes:

Carnegie Mellon Web Kilt

Components for websites and web apps on CMU's template.

FencePost

Link previews for Carnegie Mellon websites: the image and the Open Graph tags.

Forbes & Moreword

A WordPress theme in CMU style, with the kit's components ready to insert as patterns.

Jekyll & Plaid

A GitHub Pages theme that turns plain Markdown into pages in CMU style.

PlaceMellon

Placeholder photos of Carnegie Mellon at any size, for mockups and prototypes.

QRnegie

QR codes in Carnegie Mellon designs, for posters, slides and pages.
