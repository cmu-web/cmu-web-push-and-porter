A Forgejo Theme in CMU Style

Hamerschlag gives a Forgejo site Carnegie Mellon's web template: the red roof, your site's name and the CMU footer, with the Web Kilt's colors, tabs and type on every page.

Download the Theme Get Started

Get Started

  1. Download the ThemeGet the latest release, which holds the files for your Forgejo's custom folder.
  2. Copy It Into ForgejoPut its templates, styles and labels in your Forgejo's custom folder and turn the theme on in app.ini.
  3. Restart ForgejoYour site keeps its own name, now under the CMU roof.
  • Your site keeps its name. The header, footer and page titles show your APP_NAME; the theme never names itself on your site.
  • It's a theme, not a fork. Forgejo runs as it is; the theme uses Forgejo's own spots for additions.
  • Check it on every Forgejo update. A few files follow Forgejo's version; see what to recheck.

What It Changes

  • Header: the template's red roof with the Carnegie Mellon wordmark, your site's name and an optional line under it, and Forgejo's menu as the template's tab strip.
  • Footer: the template's dark footer with your site's name and address, Legal Info and www.cmu.edu. Forgejo's own footer bar is gone.
  • Tabs: repository, explore and pull request tabs in the Kilt's look: the current one red and underlined, counts as quiet gray numbers.
  • Language: Forgejo's language menu at the top right of the roof.
  • Colors, type and labels: the Kilt's red, grays and Open Sans, square corners, and menus and buttons in Title Case.

Install the Hamerschlag theme on this Forgejo instance. Download the latest release of https://github.com/cmu-web/cmu-web-hamerschlag and copy its custom/public, custom/templates and custom/options folders into the instance's custom folder (CustomPath, often /var/lib/forgejo/custom, or /var/lib/gitea/custom in the container), and stop to ask before overwriting any file the instance already has there. In app.ini, keep the site's own APP_NAME (the theme shows it as the site's name and never names itself), add hamerschlag to [ui] THEMES and set DEFAULT_THEME = hamerschlag; under [other], set SHOW_FOOTER_POWERED_BY and SHOW_FOOTER_VERSION to false. If the site wants a line under its name or its own footer address, edit custom/templates/custom/hamerschlag/site_line.tmpl or address.tmpl. Restart Forgejo. Then compare the instance's Forgejo version with FORGEJO in the release's scripts/build.mjs: if they differ, check that custom/header.tmpl, custom/body_inner_pre.tmpl and custom/footer.tmpl are still empty extension points in that version, and rebuild the labels with node scripts/build.mjs after setting FORGEJO to the instance's version, or remove custom/options and keep Forgejo's own labels.
